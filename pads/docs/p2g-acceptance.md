# P2 第七批：项目库脚号映射与歧义报告

日期：2026-11-07。版本：0.8.0。基于上一批的建议，先为隐式脚号、多单元和非符号
供电脚建立只读证据；本批不扩大修改、打包或正式库写入范围。

## 本批成果

新增 `inspect_pads_pin_mapping`，领域工具总数为 24。它位于 `edit` 工具组，复用
测试副本策略、应用会话绑定和操作锁，但不调用原理图、打包或库修改接口。
输入为绑定会话、已有设计、1–4 个准确位号和可选的同范围基线。

读取工程实际使用的 `Integration/LocalPartsDB.pdb`，先复制到独立证据目录，再由
已安装的原生 `PartsDB2HKP.exe` 导出指定 Part，使用 `DataConvert.exe` 转换为
ASCII_PDB 02.01。仅解析受支持的 Symbol、SwapGroup、Slot 和脚属性结构，依次核对：

1. 实时 Part Number、符号分区/名称、完整实例路径、原生器件/引脚 UID。
2. 整个符号单元的脚名与显式脚号，必须唯一匹配一个库 Slot；不根据网络名称猜测。
3. 新鲜 SCT 的物理脚号/脚名，以及 SCT 与 Allegro 一致的完整逻辑网络图。
4. 再次读取实时实例并重复双格式导出；核对来源文件、工具、实例身份和工程路径未变。

报告区分显式脚号、唯一 Slot 补全的隐式脚号、多个单元共用的物理脚、没有实时图形
端点的非符号供电脚，以及未放置的符号 Slot。歧义和冲突返回 `needs_review`，保留
候选 Slot 与原始观察值；不会把未解析结果记为核验通过。来源或快照变化直接拒绝
记录新基线。基线比较范围包括映射与 Part 结构，来源 PDB 或程序变化后要求重新建基线。

## 发现的问题和范围限制

- `DataConvert` 在本机成功转换时退出码为 1。仅当无标准输出/错误诊断、目标存在、
  结构完整且准确匹配请求 Part 时才接受；退出码本身不代表成功。
- 同一全局电源在局部页可叫 `PWR`，不能强制局部名称等于扁平化网络名。Slot 依赖
  明确脚号和整单元脚名匹配；网络归属使用双格式原生导出，并检查局部导线不被映射
  到互相冲突的逻辑网络。
- 项目有效 PDB 不保证等于当前中央库；本工具明确返回
  `central_library_equivalence_verified=false`。其他 PADS 版本、额外 PDB 搜索路径、
  直接总线段映射和未支持的导出结构尚不支持，遇到时拒绝猜测。
- 查询限四个有效 Part、十六个选定实例、128 个选定实时引脚，最多扫描一万个器件。
  每个原生 Part 导出/转换限 25 秒，总原生工作进程 180 秒、上层 270 秒。未在最大
  限额和超大工程完成性能验收。
- 只读指不修改设计和库；证据目录会生成私有 PDB、导出及报告，编辑器服务也可能
  维护辅助文件，不宣称整个测试目录逐字节不变。不能锁住用户在另一个界面的编辑。
- `write_authorized`、`full_design_pin_mapping_verified`、`full_erc_verified` 均为 false。
  此次没有新增执行/恢复功能，上一批打包仍仅支持明确脚号、单个未连接器件和空 BAM。
