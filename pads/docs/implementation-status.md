## P1：MCP 与只读能力——本机只读范围验收完成

已交付：

- 独立 Rust MCP 服务、按组发现工具、参数校验、规范化工具错误。
- 十个领域工具：原有五个参考/环境工具，以及会话绑定、实时核验、工程盘点、快照比较和释放绑定。
- 三份手册共 6521 页建立本地全文索引，查询前校验来源 SHA-256 和页数完整性。
- 原生激活仅保留为开发诊断入口；MCP 不暴露任意 COM、脚本或命令执行能力。
- Python 工作进程单次调用、90 秒期限；原生读取 60 秒期限。文档证据、静态接口和运行验证明确区分。

本次验收：31 项 Python 测试、8 项 Rust 测试通过。实际工程中读得 11 张原理图、
566 个器件类对象（119 个不同非空位号）、903 个网络对象；PCB 为 121 个器件、
320 个默认集合内网络。两端 119 个原理图位号全部对应，PCB 另有 TV1、TV2。
原理图和 PCB 各完成 11 个实际 MCP 请求的会话流程。详细证据和限制见
[P1 验收报告](p1-acceptance.md)。

完成的 P1 验收项：

1. 绑定并核验实例 GUID、PID、进程启动时间、安装路径、规范化工程路径及工程文件指纹。
2. 隔离完整示例的真实对象读取、原生 UID 和已列出属性读回一致性核验。
3. 实际工程切换、关闭后拒绝、显式重连，以及真实弹窗阻塞和超时错误反馈；单元测试覆盖异常分支和并发释放。
4. 实现只读快照及显式比较契约。完整几何/引脚拓扑校验、修改预览和写入事务留在 P2；当前快照不构成写入许可。
