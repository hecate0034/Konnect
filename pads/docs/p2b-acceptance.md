# P2 第二批：导线几何、恢复、复用放置与指定引脚连接

日期：2026-11-06。开发版本：0.3.0。范围为本机 PADSProVX.2.4 / COM 66 的隔离测试副本。
后续多段路径、已有网络接入和原生检查见 [P2 第三批验收](p2c-acceptance.md)。

## 本批实现

新增五个 MCP 工具，领域工具总数由 14 增至 19：整页检查、修改预览、一次性执行、
恢复预览和关闭重开核验。仍使用原有绑定身份、工程路径和测试副本配置检查。
预览和结果持久记录在本机 SQLite；修改与恢复共用执行锁和十分钟预览期限。

| 功能 | 本批约束与检查 |
| --- | --- |
| 导线几何 | 记录端点、连接类型、引脚坐标/网络身份；检查引脚端点间隙和零长度线段；移动预览拒绝跨越其他网络、无关引脚和器件本体 |
| 已有器件修改 | 保留属性白名单；已连接器件仅允许保持直线的平行端点移动，拒绝需要原生自动折线的移动 |
| 恢复 | 当前整页必须仍等于该操作记录的实际后态；按逆序恢复，拒绝覆盖后续改动；恢复后再次读回和重开 |
| 复用放置 | 从同页已有器件取得 Symbol 分区、Part/Cell 属性和脚号，实例化既有符号；复制有效实例属性，不创建库定义 |
| 指定引脚连接 | 两个不同器件的空闲、带脚号引脚；单段水平/垂直导线；返回网络必须只有预期线段和两端连接 |

整页比较覆盖已读取的组件身份、符号/分区、属性原值/实例值/有效值、位置、方向、
包围框、引脚脚号/坐标/网络 UID，以及网络名称、线段端点、连接类型和总线标志。
无位号图形对象的保留属性 `@DATETIME` 会由 PADS 自动刷新，明确排除出比较。
“恢复基线”指上述记录字段一致，不表示数据库逐字节还原，也不等于完整 ERC。

## 实际遇到的问题及处理

1. **坐标被默认网格取整。** C2 的 x=855 在原网格下被原生接口吸附为 850，
   并产生非预期折线。执行后整页比较正确报告失败；记录实际后态后，通过显式恢复
   还原属性、位置和导线，并在重开后验证。现写入期间使用原生网格参数值 1，finally
   恢复并核验原参数；不把网格参数的原始数值与器件坐标单位混用。
2. **放置接口不会完整复制实例。** `AddPartInstance` 的分区参数需要符号分区 `Sample`；
   单独调用不会复制所有有效属性和脚号。现在显式复用原实例元数据并验证新实例，
   不声称已完成中央库 Part 数据库的完整封装/多单元解析。
3. **原生引脚引用失效。** 分两次调用 `DesignComponents` 查找两端后，较早取得的 COM
   引脚句柄会失效，AddNet 返回对象集合错误。失败后的整页读回确认没有新增网络。
   改为从同一保留的活动页集合解析两端，并正确传递原生 IDispatch；实际连接和逆序恢复均通过。
4. **页读取耗时。** 全设计枚举后筛选页不适合重复几何验证；改为核验活动页后查询该页。
   原生整页调用期限为 180 秒，外层工作进程 270 秒；较大的工程仍需另行验收。

已观测的部分属性/位置修改、目标移动及其附属网络变化可进入有条件恢复。
未知超时、未记录后态或不符合支持模式的部分放置/连线拒绝自动逆转；保留副本供检查。
恢复本身也不是原子事务，不承诺失败时自动回滚。

## 检查与边界

- Python：78 项通过，覆盖几何相交/间隙、碰撞拒绝、网格恢复、单次预览、过时状态、
  已观测部分失败恢复、未知结果拒绝、会话/工程隔离，以及既有 P0/P1/P2a 回归。
- Rust：11 项通过；格式检查和 Clippy（warnings as errors）通过。
- 实际只读 MCP 回归：11 个响应通过，手册检索、类型库查找和参数拒绝正常。
- 不支持任意旋转、多单元封装解析、接入已有网络、网络合并、跨页/层次连接、总线编辑、
  多段路径或全自动布线；没有完整网络表/ERC、PCB 同步或生产工程验收。
- 元件包围框用于保守碰撞检查，不覆盖所有文字/图形；不做图纸边界检查。
- 配置/清单和中央库描述文件指纹不是递归库锁；验收另外校验复制库和 PCB 文件哈希。
  操作期间不得手动改工程/库或切换工程；跨状态目录运行的执行器不会相互锁定。
- 仅本机 COM 66 验证，其他版本、500 个以上器件类对象或 2,000 个以上网络的页未验收。
