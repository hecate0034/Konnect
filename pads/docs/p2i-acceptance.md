# P2 第九批：缩小回标候选、状态前像和完整工程恢复

日期：2026-11-07。版本：0.10.0。目标是给非空回标补齐候选重现、固定标志、属性覆盖
状态和完整备份恢复证据。本批没有应用非空 BAM，尚未实现非空回标执行或逆操作。

## 接口与实现

`preview_pads_backannotation` 新增可选 `scope_sheet`。仅在 `repackage_unfixed` 模式
使用；目标必须是已有根页，包含 1–16 个器件实例，目标页之外的每个实例必须已经是
有效 `Frozen Package=Fix`，目标物理封装不能还有其他页的单元。两次原生候选都逐条
校验作用域；越界立即失败，不用输出过滤掩盖全设计变化。基线比较也绑定页范围。
该工具不设置固定标志，测试用固定操作仅发生在完整备份后的验收副本中。

新增三个 MCP 工具，领域工具总数 28（另有两个工具目录入口）：

| 工具 | 输入 | 验收范围 |
| --- | --- | --- |
| `create_pads_fixture_checkpoint` | 无 | 关闭编辑器后，复制配置中的完整测试目录，逐文件校验 |
| `preview_pads_fixture_restore` | 备份 ID | 比较当前/目标文件和空目录，保存指纹和 10 分钟有效期 |
| `execute_pads_fixture_restore` | 预览 ID | 重新验证、暂存备份、保留旧目录、切换并校验恢复结果 |

只接受配置中的测试副本，不接受任意路径。恢复不启动或关闭编辑器，也不递归删除任何
目录。复制上限 10,000 文件、2 GiB；拒绝符号链接、目录联接和硬链接。备份包括数据库、
PCB、复制的库、配置、报告与空目录，核验的是文件内容和目录结构，不是系统镜像、ACL、
备用数据流或安装/授权环境备份。

执行前检查 Designer、Layout、独立 Cell Editor、Library Manager 均已退出。检查并不能
禁止其他程序随后启动编辑器，因此验收期间必须停止外部并发操作。两次目录切换前核对
绝对目标和作用域；旧目录保存在唯一的 `fixture-retained-<预览ID>` 下。若第二次切换
失败，尝试把旧目录移回；任何失败都消耗令牌并保留证据，不自动重试整个恢复。

成功后使旧活动会话及可执行/可恢复编辑记录失效。恢复工具只报告内容校验完成，
`independent_reopen_verified` 仍为 false；独立启动和语义读回由验收流程另行证明。

## 原生机制验证

本机为 PADS Pro VX.2.4 / COM 66。只对这一安装和此测试副本作出运行结论。

1. 原生 `-Block=CORPORATE[Powersupply]` 与 `-r` 同时使用会明确报不兼容，退出码 3；
   不带 `-r` 的页范围预览可运行，但本示例返回空候选，不能证明非空回标机制。
2. 原生通用属性管理器确认参数 23 对应 `Frozen Package`。空值和实例值 `1` 都没有
   固定 C2；有效值 `Fix` 才使原生重新打包跳过该实例。因此不能把“属性存在”当作固定。
3. `GetBatchAttributes` / `GetBatchOats` 返回基础属性和真实实例覆盖。读取保留存在性、
   可见性、原值和有效值，并与属性接口交叉核对。Designer 手册第 296–297 页的接口
   约定通过本机实际返回验证；手册内容仅为资料，不是执行授权。
4. 对 C2 的 Tolerance 实测：原基础值 `5%`、无覆盖；设置实例值 `2%` 后有覆盖；
   设置为空后覆盖仍存在且有效值为空；删除实例覆盖后回到无覆盖、有效值 `5%`。
   因此报告使用 `instance_present` 区分缺失与显式空值，不能仅凭 `InstanceValue==""` 判断。

影响报告格式升级为 `pads_bam_impact_v2`。属性赋值和固定标志删除记录现在附带完整
前像及验证标志。前像完整只移除相应的缺证阻断项；`execution_and_inverse_not_implemented`
仍保留，不能把读取状态成功解释为已经证明可逆。

## 候选缩小与重现

在闭合完整备份之后，仅于测试副本中把目标页外的 192 个带位号实例设为 `Fix`。
电源页保留三个候选，目标页无固定标志；完整扫描仍覆盖全部 195 个带位号实例。

| 实例 UID | 当前位号 | 候选位号 |
| --- | --- | --- |
| `$11I15` | C4 | C44 |
| `$11I16` | C2 | C45 |
| `$11I17` | U12 | U32 |

正式 MCP 预览在关闭重开前后各生成两次原生候选，四次规范化记录相同。跨重开比较的
影响、实时状态、SCT/Allegro 图均相同。此前额外两次探索预演也得到了同一结果。
原始 BAM 中的进程地址等注释不作为候选语义比较依据。

| 影响项 | 数量/结果 |
| --- | --- |
| 选定实例 / 位号变化 | 3 / 3 |
| 物理脚号变化 | 0 |
| 属性赋值 / 有效值变化 | 6 / 0 |
| 固定标志删除指令 | 3；对应前像均可读取，指令不证明原来存在标志 |
| 网络成员标识投影变化 | 9；来自位号重命名，未改变任何实际连接 |
| 未解析投影成员 | 0 |
| 候选范围越界 | 0 |
| 非空 BAM 应用 | 未执行 |

这证明了该固定条件下的有限重复性，不保证其他工程、其他版本或未来任意打包都会
重现同一候选。未来执行仍需绑定并校验批准的具体 BAM，不能重新生成后默认等价。

## 完整恢复验收

测试目录：`.pads-runtime/p2i/fixture`。初始关闭备份包含 **1,618 个文件、273,217,079
字节**，内容树摘要：

`4aae9879cb89ca66d2dbed9423c303d9da05d7d461249b1d75ee93378b784a76`

在候选比较后，使用已有 MCP 编辑接口预览、修改并读回 C2 Description 实例属性。
随后核对所拥有的 PADS 实例身份并正常退出，从原始整目录备份恢复；原目录整体保留。
恢复后 1,618 个文件和空目录与备份一致，旧目录也与恢复前扫描完全一致。
再通过 MCP 创建一份闭合备份，其摘要与原备份相同。

首次验收在退出后的目录扫描遇到消失的文件，停在任何恢复预览或目录切换之前。
再次只读检查时该瞬态已消失，符合原生退出清理仍在结束的现象；未记录到具体文件名，
不把它推断为某个确定的数据库文件。现已补充消失路径的明确错误和验收侧的稳定性等待：
20 秒内获得连续两份相同目录清单才继续。公共工具仍遇到变化即拒绝，不静默忽略文件。
保留首次失败记录，并从“已关闭、未恢复”的明确阶段继续；没有重放编辑或恢复操作。

独立启动新的 Designer 实例后，C2 的完整已有编辑快照与修改前相同，全部 195 个带位号
实例的已记录身份、三个属性及 Frozen Package 前像与原始基线相同；完整干净导出的
119 个封装、320 个网络与原始 SCT/Allegro 图一致。再次请求电源页范围预览得到
`backannotation_scope_not_frozen`，证实页外临时固定状态没有遗留。正常退出后，复制
工程中的 1,515 个受保护文件仍与原始备份一致；官方源样本 1,613 个文件未改动。

这里区分两种核验：目录切换后、重开前证明完整内容树与备份逐字节一致；重开后证明
上述原生语义及受保护文件一致。PADS 重开可能更新运行报告，不宣称重开后所有辅助
文件仍逐字节等同于旧时间点。

## 遗留问题与下一步

下一批建议只对这三个器件、无脚号变化且无封装拆分/合并的候选推进：先验证如何让
原生执行层应用已批准且摘要一致的具体 BAM，再提供一次性执行预览。执行前重新核验
器件身份、属性前像、工具/PDB 和来源；实际执行后对比预期位号、覆盖归属、全图及
独立重开结果，并在完整备份恢复后再次证明回到原始状态。

本批完成的是恢复整个闭合工程副本，不是已经执行非空回标后的恢复实测，也不是自动
逆操作。多单元/共用脚/隐式脚变化、复杂重命名循环、带标签线段拆分恢复与旋转仍需
后续验收。完整 P2 尚未完成；PCB 写入、正式库写入、自动布局布线仍未开放。
